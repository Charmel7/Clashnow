1. Introduction

CLASHNOW remplace les buzzers physiques par une solution logicielle simple à déployer en réseau local. Le système sépare deux rôles : l'animateur (application Admin sur Windows) et les participants (application Joueur sur Android). Objectifs : rapidité de déploiement, traçabilité des scores, et gestion équitable des tours.

Public et cas d'usage

  • Animateurs de clubs, professeurs et organisateurs d'événements.
  • Participants : adolescents et étudiants (usage pédagogique et ludique).

Avantages face aux buzzers physiques

  • Pas de matériel supplémentaire à acheter.
  • Export des statistiques, pénalités et verrouillages logiciels.
  • Possible simulation et tests depuis l'admin.

2. Installation

Prérequis

RôleOS / Requis
AdminWindows 10+, port TCP 8080 ouvert, 100 MB libre
JoueursAndroid 7+ (APK), Wi-Fi sur le même réseau

Étape A — Installer l'Admin (Windows)

Action : Décompressez clashnow_windows.zip et lancez l'exécutable. Autorisez le pare-feu si nécessaire.

Placez l'application dans un dossier local (pas sur lecteur réseau) pour éviter les problèmes de droits.

Étape B — Installer l'application Joueur (Android)

Action : Copiez clashnow_android.apk sur chaque appareil et installez (autoriser sources inconnues si demandé).

Important : tous les appareils doivent être sur le même réseau local. Ne pas inclure le port dans l'IP (côté joueur, saisir uniquement l'adresse IPv4 affichée par l'admin).

Récapitulatif rapide

  1. Démarrer l'admin sur la machine Windows (SERVER).
  2. Noter l'IP affichée (ex. 10.13.21.127).
  3. Les joueurs saisissent l'IP, leur nom et équipe, puis se connectent.

3. Guide Admin

Démarrer et préparer la partie

SERVER : lance le serveur TCP sur le port 8080. Après démarrage l'interface affiche l'IP et l'état « En attente de joueurs... ».

Contrôles de partie

Utilisez les boutons : START (démarrer), NEXT (question suivante), PAUSE (suspendre), STATS (afficher statistiques), EXPORT (CSV).

BoutonFonction
SERVERDémarrer/arrêter le serveur
STARTDébut de la partie
NEXTQuestion suivante (réinitialise les buzzers)
PAUSESuspendre la partie
STATSAfficher statistiques détaillées
EXPORTExporter les résultats en CSV

Gestion des joueurs

La liste des joueurs se met à jour en temps réel. Indicateur vert = connecté, rouge = déconnecté. Possibilité de désigner un capitaine via l'icône dédiée.

Réception d'un buzz et attribution des points

À la réception d'un buzz, un modal s'affiche avec : nom du joueur, équipe, choix de points (+5, +10, +20, +30, +40) et option PASSER ou pénalité -10.

Conseil : utilisez PASSER pour bloquer l'équipe actuelle après une mauvaise réponse et donner la chance à l'équipe adverse.

Statistiques et export

Stats disponibles : scores individuels, agrégés d'équipe, temps de buzz, nombre de tentatives. Export CSV pour archivage ou analyse.

4. Guide Joueur

Connexion au salon

  1. Ouvrez l'application.
  2. Saisissez l'IP affichée par l'admin (ex. 10.13.21.127).
  3. Entrez votre nom et choisissez une équipe (EQUIPE A / EQUIPE B).
  4. Appuyez sur « Rejoindre ».

Écran buzzer et interaction

Le joueur dispose d'un grand bouton \"buzzer\". La barre d'espace peut aussi déclencher le buzz sur les appareils avec clavier.

Si votre buzzer est verrouillé, attendez que l'admin clique sur NEXT ou déverrouille l'équipe.

Affichage du score

Les mises à jour de score sont transmises via des messages JSON et s'affichent en temps réel sur l'écran joueur.

{
  "type": "score_update",
  "playerId": "John_EQUIPE A",
  "points": 10,
  "totalScore": 50
}

5. Fonctionnalités avancées

Système de capitaines

Possibilité de désigner des capitaines ; affichage d'une icône dédiée et options de gestion spécifiques.

Points et pénalités

Points configurables selon la difficulté : +5, +10, +20, +30, +40 ; pénalité standard : -10.

Verrouillage stratégique

Après attribution d'un point, l'admin peut verrouiller/déverrouiller les équipes pour contrôler le flux des buzz.

6. Protocole réseau

Communication via sockets TCP JSON sur le port 8080. Exemples de messages :

Connexion joueur

{
  "type": "player_join",
  "playerName": "John",
  "teamName": "EQUIPE A",
  "playerId": "John_EQUIPE A"
}

Buzz joueur

{
  "type": "buzz",
  "playerName": "John",
  "teamName": "EQUIPE A",
  "timestamp": "2024-01-01T10:30:00Z"
}

Attribution de points

{
  "type": "score_update",
  "playerId": "John_EQUIPE A",
  "points": 10,
  "totalScore": 50
}

7. Dépannage

Problèmes réseau courants

  1. Vérifier que l'admin a bien cliqué sur SERVER.
  2. Confirmer que l'IP saisie par les joueurs est exacte (pas de :8080).
  3. Vérifier que l'ensemble des appareils est sur le même réseau Wi-Fi.
  4. Vérifier le pare-feu Windows ou blocage du port 8080.

Bugs connus et solutions

  • Lenteur sur réseau encombré → basculer sur point d'accès dédié.
  • APK non installable → autoriser « sources inconnues », vérifier la signature.
  • Admin qui se fige → redémarrer l'application et exporter les stats régulièrement.
Astuce : faire un test de simulation avant la partie complète (2–3 joueurs) pour vérifier la configuration réseau.

FAQ

Combien de joueurs peuvent se connecter simultanément ?

Aucun verrou strict, mais pour une expérience fluide 4–12 joueurs (2–6 par équipe) est recommandé, selon la qualité du réseau.

L'application fonctionne-t-elle sur WAN ?

Elle est conçue pour LAN. L'utilisation sur WAN nécessite routage/NAT et précautions de sécurité supplémentaires.
