Qu'est-ce que CLASHNOW ?

Une application moderne qui remplace les buzzers physiques pour les compétitions de génie en herbe.

Économique

Utilisez vos appareils existants (PC + smartphones)

Instantané

Détection du premier buzz en temps réel

Intelligent

Statistiques détaillées, export des résultats

Simple

Interface intuitive pour tous les âges

Architecture du Système

Admin Windows
→
Joueur Android
Tous les appareils sur le même réseau WiFi = Communication instantanée

👑 Panneau Administrateur

  • SERVER : Démarre le serveur et affiche l'IP
  • START : Lance la partie (active les buzzers)
  • Gestion des buzz : Attribuer +5 à +40 points ou -10
  • STATS : Statistiques complètes en temps réel

📱 Interface Joueur

Connexion
Buzzer Actif 🔴
Buzzer Verrouillé 🔒

Connexion en 3 étapes

  1. Entrer l'IP du serveur admin
  2. Saisir son nom et choisir son équipe
  3. Buzzer dès que prêt !

💻 Prérequis Techniques

Admin (Windows)

  • Windows 10+
  • 50 MB d'espace
  • Connexion WiFi
  • Port 8080 disponible

Joueurs (Android)

  • Android 8.0+
  • 50 MB d'espace
  • Connexion WiFi
  • Même réseau que l'admin
⚠️ Important : Tous les appareils doivent être sur le MÊME réseau WiFi

📥 Installation Rapide

1️⃣ Admin

  1. Télécharger clashnow.zip
  2. Extraire les fichiers
  3. Lancer clashnow.exe
  4. Cliquer sur SERVER

2️⃣ Joueurs

  1. Transférer clashnow.apk
  2. Autoriser sources inconnues
  3. Installer l'APK
  4. Se connecter avec l'IP admin

⏱️ Temps d'installation : ~5 minutes
