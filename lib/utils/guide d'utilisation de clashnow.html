Introduction

Qu'est-ce que CLASHNOW ?

CLASHNOW est une application moderne qui remplace les buzzers physiques traditionnels pour les compétitions de génie en herbe. Elle permet aux clubs et écoles d'organiser des quiz interactifs en équipe avec un système de buzz numérique professionnel.

Pourquoi choisir CLASHNOW ?

💰 Économique

Plus besoin d'acheter du matériel coûteux. Utilisez simplement vos appareils existants.

📱 Flexible

Fonctionne sur Windows (admin) et Android (joueurs). Connexion via WiFi local.

📊 Complet

Statistiques détaillées, export CSV, gestion des capitaines, et bien plus.

⚡ Instantané

Buzz en temps réel avec affichage immédiat du premier joueur.

Public cible

  • Clubs de génie en herbe
  • Établissements scolaires
  • Animateurs de quiz
  • Organisateurs d'événements éducatifs

📱 Guide Joueur

L'application joueur est simple et intuitive. Elle permet de se connecter au salon et de buzzer rapidement.

1

Lancer l'application

Écran d'accueil côté joueur

Action : Ouvrir l'application CLASHNOW sur votre appareil Android

Vous arrivez sur l'écran d'accueil avec deux options :

  • CRÉER SALON : (Non utilisé côté joueur)
  • REJOINDRE SALON : Cliquez ici pour vous connecter
2

Remplir le formulaire de connexion

Formulaire de connexion (vide)

Action : Entrer vos informations de connexion

Champs à remplir :

  1. IP DU SERVEUR ADMIN
    • Entrez l'adresse IP affichée sur l'écran admin
    • Exemple : 10.13.21.127 ou 172.20.10.5
    • Ne pas inclure le :8080, seulement l'IP
  2. VOTRE NOM
    • Choisissez un nom ou pseudo
    • Ce nom apparaîtra à l'écran quand vous buzzez
    • Exemple : Emilien, Alice, Bob, etc.
  3. ÉQUIPE
    • Sélectionnez EQUIPE A ou EQUIPE B
    • Utilisez le menu déroulant
💡 Conseil Demandez à l'animateur de vous donner l'IP exacte et votre équipe assignée avant de commencer.
3

Se connecter au salon

Connexion réussie : le joueur est connecté au salon

Action : Cliquer sur le bouton "SE CONNECTER AU SALON"

Connexion réussie :

  • Message "Connecté !" s'affiche avec une coche verte ✓
  • Vous êtes redirigé vers l'écran de buzzer
  • Votre nom apparaît sur l'écran admin
Erreur de connexion : vérifiez l'IP et le réseau

Erreur de connexion :

Si un message d'erreur rouge apparaît :

  • "Impossible de se connecter à [IP]:8080"
  • Vérifiez l'IP du serveur admin (pas d'erreur de frappe)
  • Vérifiez que vous êtes sur le même réseau WiFi
  • Vérifiez que le serveur admin est bien démarré (bouton SERVER cliqué)
  • Assurez-vous que le port 8080 n'est pas bloqué
⚠️ Problème courant Si vous ne pouvez pas vous connecter, le problème vient souvent d'un réseau WiFi différent. Vérifiez que tous les appareils sont sur le MÊME réseau.
4

Utiliser le buzzer

Buzzer actif (prêt à buzzer)
Buzzer verrouillé après un buzz

Interface de jeu :

L'écran affiche :

  • Votre nom en haut
  • Votre équipe (EQUIPE A ou B)
  • Votre score personnel
  • Le gros bouton buzzer au centre
  • Message en bas : "APPUYEZ POUR BUZZER"

États du buzzer :

🔴 Buzzer actif (rouge) :

  • Vous pouvez appuyer pour buzzer
  • Le bouton est grand et rouge avec icône de son 🔊
  • Message : "APPUYEZ POUR BUZZER"

🔒 Buzzer verrouillé (gris) :

  • Vous ne pouvez pas buzzer
  • Le bouton est gris avec icône de cadenas 🔒
  • Message : "Buzz envoyé ! En attente du premier buzzer..."
  • Apparaît après que vous ou votre équipe avez buzzé
💡 Astuce de rapidité Soyez prêt ! Le premier à buzzer a la priorité. Gardez votre doigt près du bouton dès que la question est posée.
5

Suivre votre score

Votre score personnel est affiché en temps réel en haut de l'écran.

Mise à jour du score :

  • Après chaque buzz, l'admin attribue des points
  • Votre score se met à jour automatiquement
  • Les points peuvent être positifs (+10, +20, etc.) ou négatifs (-10)
ℹ️ Score d'équipe Le score de votre équipe est visible sur l'écran admin. Seul votre score personnel s'affiche sur votre appareil.

1️⃣ Connexion

2️⃣ Attente

Attendez que l'admin démarre la partie. Votre buzzer sera alors actif.

3️⃣ Jeu

Écoutez les questions et buzzez le plus vite possible quand vous connaissez la réponse.

4️⃣ Scores

Suivez votre progression et tentez de devenir le top scorer !

Système de capitaines

Capitaine d'équipe (étoile / couronne)

Les capitaines d'équipe ont une étoile ⭐ affichée à côté de leur nom.

Comment désigner un capitaine :

  1. Cliquez sur le nom d'un joueur dans la liste admin
  2. Un menu d'options apparaît
  3. Sélectionnez "Désigner comme capitaine"
  4. L'étoile ⭐ apparaît à côté de son nom
ℹ️ Rôle du capitaine Le statut de capitaine est principalement honorifique. Il peut servir à identifier le porte-parole de l'équipe (ou le joueur le plus expérimenté).

Système de points flexible

L'admin peut attribuer différents points selon la difficulté de la question :

Points Utilisation suggérée
+5 points Bonus pour réponse partielle ou question bonus facile
+10 points Question standard de difficulté normale
+20 points Question de difficulté moyenne ou identification
+30 points Question difficileou identification
+40 points Question très difficile ou identification
-10 points Pénalité pour mauvaise réponse ou mauvaise conduite de joueur

Gestion du verrouillage stratégique

Dialogue d'options admin et boutons de simulation
Gestion des pénalités et options lors d'un buzz

Le système de verrouillage permet une gestion équitable des buzz :

Scénario 1 : Réponse correcte

  1. Un joueur de l'EQUIPE A buzz
  2. Il donne la bonne réponse
  3. L'admin attribue les points (+10, +20, etc.)
  4. TOUS les buzzers se verrouillent
  5. L'admin clique sur NEXT pour la question suivante

Scénario 2 : Réponse incorrecte avec option PASSER

  1. Un joueur de l'EQUIPE A buzz
  2. Il donne une mauvaise réponse
  3. L'admin clique sur PASSER
  4. L'EQUIPE A est verrouillée (ne peut plus buzzer)
  5. L'EQUIPE B est déverrouillée (peut buzzer)
  6. Si l'EQUIPE B répond correctement, elle gagne les points

Scénario 3 : Pénalité immédiate

  1. Un joueur buzz avec une mauvaise réponse
  2. L'admin clique sur -10 POINTS
  3. Le joueur perd 10 points
  4. Son équipe perd également 10 points
  5. Tous les buzzers se verrouillent
💡 Stratégie d'animation Utilisez PASSER pour donner une réplique à l'autre équipe. Utilisez -10 pour pénaliser les réponses complètement fausses ou les mauvaises conduites.

Statistiques détaillées

Statistiques détaillées du match

Le panneau de statistiques offre une analyse complète de la partie :

Métriques individuelles :

  • Tentatives : Nombre de fois où le joueur a buzzé
  • Réussites : Nombre de bonnes réponses
  • Efficacité : Pourcentage de réussite (Réussites / Tentatives × 100)
  • Score : Points totaux accumulés

Métriques d'équipe :

  • Score total de chaque équipe
  • Nombre de tentatives par équipe
  • Taux de réussite global par équipe
ℹ️ Interprétation Un joueur avec peu de tentatives mais un score élevé est très efficace. Un joueur avec beaucoup de tentatives mais peu de points buzz trop souvent sans connaître la réponse.

🔧 Dépannage

Problèmes de connexion

❌ Les joueurs ne peuvent pas se connecter

Solutions :

  1. Vérifiez que le serveur admin est bien démarré (bouton SERVER cliqué)
  2. Vérifiez que l'IP entrée par les joueurs est correcte (pas d'espace, pas de :8080)
  3. Assurez-vous que tous les appareils sont sur le MÊME réseau WiFi
  4. Redémarrez le routeur WiFi si nécessaire
  5. Désactivez temporairement les pare-feu qui pourraient bloquer le port 8080
  6. Essayez de pinguer l'IP de l'admin depuis un appareil Android (avec une app de ping)
❌ Un joueur est déconnecté en cours de partie

Solutions :

  1. Le point à côté de son nom devient rouge sur l'écran admin
  2. Demandez au joueur de vérifier sa connexion WiFi
  3. Le joueur peut se reconnecter avec les mêmes informations
  4. Son score sera préservé s'il utilise exactement le même nom et la même équipe
❌ L'admin ne voit pas l'IP du serveur

Solutions :

  1. Vérifiez que l'ordinateur est bien connecté au WiFi
  2. Redémarrez l'application CLASHNOW
  3. Trouvez manuellement l'IP avec la commande ipconfig dans l'invite de commandes
  4. Assurez-vous qu'aucun VPN n'est actif

Problèmes de buzz

❌ Le buzzer ne répond pas quand on appuie

Solutions :

  1. Vérifiez que la partie est démarrée (bouton START cliqué côté admin)
  2. Vérifiez que le buzzer n'est pas verrouillé (icône de cadenas)
  3. Si votre équipe a déjà buzzé, attendez que l'admin clique sur NEXT
  4. Vérifiez votre connexion internet (le point doit être vert côté admin)
  5. Réessayez d'appuyer fermement sur le bouton
❌ Le buzz n'arrive pas à l'admin

Solutions :

  1. Problème de latence réseau : vérifiez la qualité du WiFi
  2. Rapprochez les appareils du routeur WiFi
  3. Fermez les applications qui consomment de la bande passante
  4. Redémarrez la connexion du joueur concerné

Problèmes d'affichage

❌ Les scores ne se mettent pas à jour

Solutions :

  1. Vérifiez que vous avez bien cliqué sur un bouton de points dans le dialogue de buzz
  2. Rafraîchissez l'affichage en cliquant sur STATS puis FERMER
  3. Si le problème persiste, notez les scores manuellement et signalez le bug
❌ L'application admin se fige

Solutions :

  1. Fermez et relancez l'application
  2. Les joueurs devront se reconnecter
  3. Les scores en cours seront perdus (utilisez l'export régulièrement)
  4. Vérifiez que votre ordinateur a suffisamment de RAM disponible

Problèmes d'installation

❌ Windows bloque l'exécution de l'application

Solutions :

  1. Cliquez sur "Informations complémentaires" dans la fenêtre Windows Defender
  2. Cliquez sur "Exécuter quand même"
  3. L'application est sûre, c'est une mesure de sécurité Windows standard
❌ Impossible d'installer l'APK sur Android

Solutions :

  1. Allez dans Paramètres → Sécurité
  2. Activez "Sources inconnues" ou "Installer des applications inconnues"
  3. Sur Android récent, vous devez autoriser l'installation pour l'application spécifique (Gestionnaire de fichiers, Chrome, etc.)
  4. Réessayez d'ouvrir le fichier APK

Conseils pour une partie réussie

💡 Avant la partie
  • Testez la connexion avec 2-3 joueurs avant d'inviter tout le monde
  • Assurez-vous que le WiFi est stable et que tous les appareils sont chargés
  • Expliquez les règles aux participants
  • Faites un tour de test avec une question facile
💡 Pendant la partie
  • Exportez les scores régulièrement (toutes les 10 questions) pour éviter la perte de données
  • Surveillez les indicateurs de connexion (points verts/rouges)
  • Rappelez aux joueurs de ne pas verrouiller leur téléphone
  • Gardez l'écran admin visible pour tous (projecteur ou grand écran)
💡 Après la partie
  • N'oubliez pas d'exporter les résultats finaux
  • Consultez les statistiques pour identifier les MVP
  • Partagez le classement avec les participants
  • Conservez les fichiers CSV pour l'historique

❓ Questions Fréquentes (FAQ)

Combien de joueurs peuvent se connecter simultanément ?

Il n'y a pas de limite technique stricte, mais nous recommandons 4 à 12 joueurs pour une expérience optimale (2 à 6 par équipe). Au-delà, le réseau peut devenir instable selon votre routeur WiFi.

Si Windows Defender affiche un avertissement, cliquez sur "Informations complémentaires" puis "Exécuter quand même". L'application est sûre.
2

Installation sur Android (Joueurs)

Icône de l'application Android (APK)

Action : Installer le fichier clashnow_android.apk

  1. Transférez le fichier APK sur chaque appareil Android (via câble USB, Bluetooth ou email)
  2. Sur l'appareil Android, allez dans Paramètres → Sécurité
  3. Activez "Sources inconnues" ou "Installer des applications inconnues"
  4. Ouvrez le fichier APK avec un gestionnaire de fichiers
  5. Appuyez sur Installer
  6. Une fois installé, l'icône CLASHNOW apparaîtra dans vos applications
⚠️ Important Tous les appareils (admin et joueurs) doivent être connectés au MÊME réseau WiFi pour communiquer.
3

Configuration réseau

Action : Vérifier la connexion réseau

Trouver l'adresse IP de l'ordinateur admin :

  1. Sur Windows, ouvrez l'Invite de commandes (tapez cmd dans la recherche)
  2. Tapez ipconfig et appuyez sur Entrée
  3. Cherchez "Adresse IPv4" sous votre connexion WiFi
  4. Notez cette adresse (exemple : 192.168.1.100)
ℹ️ Alternative facile L'application CLASHNOW affiche automatiquement l'IP du serveur une fois démarré. Notez simplement cette adresse !

👑 Guide Administrateur (Animateur)

L'interface admin vous permet de contrôler entièrement la partie : gérer les joueurs, recevoir les buzz, attribuer les points et consulter les statistiques.

1

Démarrer le serveur

Serveur admin : état arrêté / non démarré

Action : Lancer l'application et cliquer sur le bouton "SERVER"

Résultat attendu :

  • Le bouton SERVER devient gris (désactivé)
  • Le statut passe à "En attente de joueurs..."
  • L'adresse IP du serveur s'affiche (ex: 172.20.10.5:8080)
💡 Conseil Notez immédiatement l'adresse IP affichée. Communiquez-la aux joueurs pour qu'ils puissent se connecter.
2

Accueillir les joueurs

Liste des joueurs connectés côté admin

Observation : Les joueurs apparaissent automatiquement dans la liste

Pour chaque joueur connecté, vous verrez :

  • Nom du joueur : Le nom qu'il a choisi
  • Équipe : EQUIPE A ou EQUIPE B
  • Indicateur de connexion : Point vert = connecté, rouge = déconnecté
  • Statistiques : Tentatives, réussites, efficacité
  • Score personnel : Points accumulés
ℹ️ Gestion des capitaines Cliquez sur un joueur pour accéder aux options, puis choisissez "Désigner comme capitaine" pour lui attribuer une couronne 👑.
3

Démarrer la partie

Action : Une fois tous les joueurs connectés, cliquer sur "START"

Résultat :

  • Le statut change (ex: "QUESTION 1")
  • Les buzzers des joueurs deviennent actifs (rouge)
  • Le bouton START devient gris
  • Les boutons PAUSE et NEXT deviennent actifs
💡 Conseil Attendez que tous les joueurs confirment qu'ils voient leur buzzer actif avant de poser la première question.
4

Gérer les buzz

Dialogue de buzz : attribuez des points ou appliquez une pénalité

Situation : Un joueur appuie sur son buzzer

Un dialogue modal apparaît immédiatement avec :

  • Nom du joueur qui a buzzé
  • Son équipe (EQUIPE A ou B)
  • Boutons de points : +10, +20, +30, +40 points
  • Bouton +5 : Pour bonus ou points partiels
  • Bouton -10 : Pour pénalité (mauvaise réponse)
  • Bouton PASSER : Verrouille cette équipe et déverrouille l'autre

Actions possibles :

Bonne réponse :

  1. Cliquez sur le bouton de points approprié (+10, +20, etc.)
  2. Le dialogue se ferme automatiquement
  3. Le score du joueur et de son équipe est mis à jour
  4. Tous les buzzers se verrouillent

Mauvaise réponse :

  1. Cliquez sur -10 POINTS pour appliquer la pénalité
  2. OU cliquez sur PASSER pour donner la chance à l'autre équipe
  3. L'équipe du joueur est verrouillée
  4. L'autre équipe peut buzzer
⚠️ Important Une fois qu'un joueur buzz, son équipe entière est verrouillée. Seuls les membres de l'autre équipe peuvent buzzer à nouveau si vous cliquez sur PASSER.
5

Passer à la question suivante

Action : Cliquer sur le bouton "NEXT"

Effet :

  • Tous les buzzers sont déverrouillés et réinitialisés
  • Le numéro de question s'incrémente
  • Les deux équipes peuvent buzzer à nouveau
💡 Conseil Utilisez le bouton PAUSE si vous devez faire une interruption sans passer à la question suivante.
6

Consulter les statistiques

Panneau de statistiques détaillées

Action : Cliquer sur le bouton "STATS" (icône 📊)

Le panneau de statistiques affiche :

🏆 Top Scorer

  • Nom du meilleur joueur
  • Son score total
  • Nombre de tentatives et réussites
  • Taux d'efficacité

📊 Métriques globales

  • Points totaux distribués
  • Nombre total de tentatives
  • Nombre de réussites
  • Efficacité générale

🎯 Classement détaillé

Liste de tous les joueurs classés par score avec leurs statistiques individuelles.

💡 Astuce Exportez régulièrement les statistiques en cliquant sur "EXPORTER" pour sauvegarder les résultats au format CSV.
